# 🤖 Telegram бот‑финансист

Бот показывает актуальные данные по валютам, криптовалютам, акциям, товарам и индексам, умеет отправлять уведомления и ежедневную сводку.

## Возможности
- Курсы валют (USD, EUR, CNY)
- Криптовалюты (BTC, TON, SOL, USDT)
- Российские акции (MOEX)
- Товары (нефть, золото, серебро)
- Фондовые индексы
- Уведомления о резких изменениях цен
- Пороговые алерты
- Ежедневная сводка по расписанию
- Компактный DAILY со сворачиваемым блоком дополнительных данных
- Автопокупка акций через T-Invest с настройкой из Telegram

## Команды
- `/start` — старт и меню
- `/help` — справка
- `/ping [IP[:PORT] ...]` — пинг серверов и задержка (avg/min/max, loss)
- `/rates` — полная сводка рынков
- `/subscribe` — подписка на уведомления
- `/unsubscribe` — отписка
- `/set_alert <АКТИВ> <ЦЕНА>` — алерт по порогу
- `/view_alerts` — текущие настройки алертов

Админские:
- `/settings` — меню настроек
- `/export_pdf` — PDF‑отчет
- `/set_daily_time HH:MM` — время сводки
- `/get_daily_settings` — текущие настройки
- `/restart_daily_job` — перезапуск сводки
- `/test_daily` — тестовая сводка
- `/check_subscribers` — статус подписчиков
- `/autobuy_setup` — показать порядок и текущие настройки автопокупки
- `/autobuy_set_token <TOKEN>` — проверить и сохранить T-Invest токен
- `/autobuy_clear_token` — удалить токен, заданный через бота
- `/autobuy_add <TICKER> <LOTS>` — добавить количество лотов для покупки
- `/autobuy_remove <TICKER>` — удалить позицию
- `/autobuy_set_time HH:MM` — задать время покупки
- `/autobuy_on` и `/autobuy_off` — включить или выключить покупки

Токен, заданный через бота, сохраняется локально в игнорируемом Git файле
`autobuy_secrets.json` с правами доступа `0600`. Команда с токеном доступна
только администратору, а исходное сообщение удаляется сразу после обработки,
если Telegram разрешает удаление.

Количество для T-Invest задается в лотах, а не в отдельных акциях.

## Быстрый старт
```bash
cp env.example .env
# заполните BOT_TOKEN и ADMIN_USER_ID
pip install -r requirements.txt
python admin_bot.py
```

## Переменные окружения
Минимально требуется:
- `BOT_TOKEN`
- `ADMIN_USER_ID`

Остальные ключи — опционально для расширенных источников данных.
